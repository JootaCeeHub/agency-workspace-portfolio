## Overview

A single workspace for agencies and service teams: project operations, client management, kanban/list task tracking, quotes and proposal status, briefs and contracts, and team collaboration with role-based views.

## Architecture

The codebase follows a component-based architecture with typed domain models and service abstractions ready for backend integration. See the `docs/`, `src/`, or `app/` directories for the module structure.
